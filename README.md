## 開発と検証

Node.js 24以上が必要です（テストで組み込みの `node:sqlite` を使用）。
外部依存パッケージはなく、現在は `npm install` は不要です。
リポジトリのルートで実行してください。

```sh
npm test
npm run build
```

標準テストは73件です。実SQLiteと模擬画面構造による検証で、ブラウザ・iPhone・実Cloudflareの検証とは異なります。
`tests/model.test.js` と `tests/loading.test.js` は旧参照ファイルが欠落しており、標準テストから除外されています。
`node --test` で全体を自動探索すると旧テストも対象になるため、通常は `npm test` を使います。
ビルドは `public/` を `dist/` にコピーします。既存の `dist/` は作り直されるため、自作ファイルや保管データを置かないでください。
ビルド成功はCloudflare Functionsの配備・DB接続・認証の動作確認を意味しません。

## 二つの実行形態

- 本体：`public/`、`server/`、`functions/`、`migrations/`。Cloudflare Pages/Functions/D1用です。
  保存・管理画面には別途設定が必要です。今回、認証・DB・課金の追加や実環境設定は行いません。

  本体のビルドには含まれません。実際の予約情報や健康情報を入力しないでください。

ルートの `index.html` は元から改行のみです。本体の入口はFunctions、静的サンプルの入口は `samples/komorebi/index.html` です。
