## 実行済みの検証

- npm test：38件成功（旧デモ11、段階2追加14、段階3追加13）。
- 実SQLite：外部キー、版のスナップショット、CSV200件の一括SQL、冪等登録。
- テスト鍵で実際にRSA署名したJWT：正常、改ざん、失効、別audience、別発行元、未所属、他宿拒否。
- 宿側登録→URL発行→宿泊者の4項目確認→最終送信→未確認一覧から除外→申告あり一覧に表示。
- 案内改版→既存予約は旧版維持→明示的な再確認適用→旧履歴を残して未確認へ。
- OTA確認なしで直接予約をONにする操作を拒否。初期状態はOFF。
- Nodeによる本番用JSソースの構文チェック、静的ビルド、git diff --check。

これらはCloudflareの実Access、D1、実メール、ブラウザの代替とは扱いません。
