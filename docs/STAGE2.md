## 実行した検証

- npm test：25件成功。旧11件＋今回14件。
- 実SQLiteの外部キー、JSON、トリガー、一括処理のロールバックを実行。
- 予約トークンの無効・期限切れ・失効、他宿スラッグの拒否、秘密情報の非公開を検証。
- 入力不足、到着値・言語の許可値、長文、Origin、CSRF、レート制限を検証。
- 最終送信の同時再送・内容変更再送、受付結果照会、途中障害でのロールバックを検証。
- メールAPIの500応答と成功応答をスタブで検証。外部送信なし。
- 日英辞書キー一致・言語優先順・ストレージ拒否を検証。
- npm run build、主要JS構文、git diff --check：成功。
